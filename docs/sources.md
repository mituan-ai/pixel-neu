## 使用原则

- 照片只作为画图参考，不放进仓库，也不在游戏里展示。
- 一条信息只有一个来源、而且来源不够权威时，先写进 `docs/design.md` 的「待核实」，不要直接放进游戏。
- OSM 数据更新后重新跑 `npm run osm`。如果布局有变化，在提交信息里说明。
