# TASK-06：画汽车、特种车和电动两轮车

## 目标

校园里的车现在只有一种轿车换五个颜色，分不出车型。这张任务单按 `shared/vehicles.ts` 的目录，给每个车型画一套能一眼认出来的像素图。燃油车挂蓝牌，新能源车挂绿牌。

画好后图会进 `assets/vehicles.png`，场景接入由 Claude 在后面做，这张任务单不管摆放。

## 范围

`shared/vehicles.ts` 里 `group` 是 `fuel`、`nev`、`special`、`moto` 的 13 个车型。自行车和共享单车是 TASK-07，不要画。

## 依据

- 尺寸：目录里的 `size`（车长、车宽、车高，米），按 1 m = 8 px 换算后四舍五入。例如三厢轿车 4.7 × 1.8 × 1.45 m，画成 38 × 14 px 的占地、12 px 高。
- 视角和光影：根目录 `AGENTS.md`「比例与方向」、`assets/AGENTS.md`、`art/CONTRIBUTING.md`「尺度与视角」「光影与描边」。
- 画法参考：`tools/art.ts` 里的 `car()`。它是 3/4 俯视：顶面按正投影画，朝屏幕下方的那一面按真实高度竖直画在占地下沿。新车照这个画法画，细节要比它多。
- 车型特征是通用的，不对应某个品牌。不画车标、品牌字样、车牌号码。

## 相关文件（只读）

- `shared/vehicles.ts`：车型目录、`vehicleKey` 键名规则、`SCREEN_DIRS` 朝向顺序
- `tools/art.ts`：`car()` 的画法；文件末尾怎么把 `drawVehicles()` 打进图集
- `tools/pix.ts`：`Pix` 画布的方法、`Sprite` 结构
- `tools/palette.ts`：现有色板
- `tests/catalog.test.ts`：验收用的测试

## 可以改的文件

- `tools/art-vehicles.ts`：把占位图换成正式画法。`placeholder` 和 `PAINT` 两个导出保留原样，TASK-07 交付前 `tools/art-bikes.ts` 还在用。
- `tools/palette.ts`：只能在 `PAL` 末尾追加颜色，键名用 `car` 开头，例如 `carPlateB`。

## 步骤

1. **朝向。** 每个车型 × 车色 × 4 个屏幕朝向 × `frames` 帧出一张图，键名用 `vehicleKey(id, 车色号, 朝向, 帧)`。朝向是车头朝屏幕的哪一边，顺序是下、左、右、上。
   - 朝下：看到的立面是车头（大灯、格栅或封闭前脸、前牌照）。
   - 朝上：看到的立面是车尾（尾灯、后牌照）。
   - 朝左、朝右：看到的立面是车身侧面（侧窗、车门缝、两个车轮）。左右两张可以镜像，镜像后把高光挪回左上。
2. **车型特征。** 每个车型至少满足下面这一行：

   | 车型 | 必须画出的特征 |
   |---|---|
   | 三厢轿车 sedan | 前后都有突出的机舱和后备厢，座舱居中 |
   | 两厢轿车 hatch | 没有后备厢，座舱一直到车尾，车尾陡 |
   | SUV suv | 车身高，离地间隙大，车顶有行李架 |
   | MPV mpv | 车头短，座舱长而方，侧面有滑门导轨 |
   | 面包车 van | 方盒子，几乎没有车头，侧窗一排 |
   | 皮卡 pickup | 前半是双排座舱，后半是敞开的货斗 |
   | 新能源轿车 nev-sedan | 溜背，前脸封闭没有格栅，贯穿式尾灯 |
   | 新能源 SUV nev-suv | SUV 的高度，封闭前脸，贯穿式尾灯 |
   | 新能源微型车 nev-mini | 很短，两门，方头方尾 |
   | 快递三轮车 express-trike | 前面单轮带车把的驾驶位，后面方形货厢 |
   | 小型清扫车 sweeper | 方驾驶室，车底两侧有圆形扫刷 |
   | 电动自行车 ebike | 踏板车身，车把、座垫，有后座 |
   | 电动摩托 emoto | 车身更粗，前面有整流罩和大灯 |

3. **车牌。** 车头和车尾的立面上画一个 3 × 1 或 4 × 2 像素的牌照色块：
   - `fuel` 用蓝底。
   - `nev` 用绿色（上浅下深两色）。
   - `special` 用蓝底。
   - `moto` 只在车尾画一个小黄牌。
4. **车色。** 车身颜色按目录 `paints` 的名字画，用色板里最接近的颜色。每个车色要有顶面、立面、暗部三档。色板里没有合适的颜色时，追加 `car` 开头的颜色。
5. **行驶帧。** `frames` 是 2 的车型，第 1 帧的车轮花纹和第 0 帧错开一个像素，循环播放时看起来车轮在转。只有 1 帧的车型只画静止状态。
6. **投影。** 不画投影。车下的影子后面由场景按太阳方向统一画，这点和 `car()` 不一样。
7. **描边和锚点。** 外轮廓用 1 px `ink`。锚点 `(ax, ay)` 放在占地矩形中心的落地点，也就是顶面矩形下移车高后的中心。
