# TASK-22：校园漫游视频截图：收集、定位、建索引

## 目标

校内大部分楼没有能对上的照片，只能画中性立面。公开的校园漫游视频（步行、骑车、开车、航拍）沿路拍过大部分楼的临街面。这张任务把这些视频里能认出楼的画面截下来，逐张对应到楼的编号和朝向，建成索引，给后面的逐栋精修用。

这张任务**只收集和建索引**，不改 `survey.json`。

## 范围

南湖校区校内 157 栋楼（`node tools/looks.ts --list`）。重点是档案里「只有卫星图」「没资料」的楼，尤其宿舍区和南片。

## 依据

- 视频：B 站（bilibili.com）搜「东北大学 南湖校区」「东北大学 校园漫游」「东大 南湖 骑行」「东北大学 航拍」「东北大学 宿舍」「东北大学 一舍/二舍……十舍」等。只用公开发布的视频；优先 2020 年以后、画面清楚、路线连续的。
- 工具：`yt-dlp` 下载（不登录，720p 或以下就够），`ffmpeg` 抽帧（例如 `ffmpeg -ss 时间 -i 视频 -frames:v 1 截图.jpg`，或每 2 秒一帧粗看再精选）。
- 定位：截图里的楼靠这些对到编号：路的走向和路口、楼的平面形状（L 形、U 形）、层数、屋面颜色、旁边的地标（信息学馆塔楼、图书馆、体育场、汉卿会堂），和 `npm run check -- 2025-07-31 x0 y0 x1 y1 4` 的卫星图对照。**对不上编号的截图不用**，不猜。

## 文件放哪

- 视频和截图都在本地 `data/ref/video/`（这个目录主仓库里可写，不进仓库）。视频看完可以删，截图留着。
- 截图文件名：`<视频 R 号>-<mm分ss秒>-<楼编号>-<朝向>.jpg`，例如 `R-vid-03-02m15s-514987130-S.jpg`；一张里有几栋楼就按主要的那栋起名，其他写进索引。

- `docs/sources.md`：登记新的 S 号（每个用到的视频一个），写「待核实」

## 步骤

1. **找视频**：至少看 10 个候选视频，挑出 4–8 个覆盖面最大的。每个登记成 R 号（`R-vid-01`……）：链接、UP 主、发布日期、时长、路线概要（从哪到哪、经过哪些楼）。
2. **抽帧**：每个视频先每 2 秒抽一帧粗看，找出有楼的段落，再在段落里挑每栋楼最正、最清楚的一两帧。
3. **定位**：每张截图对到楼编号和朝向（这张照的是楼的哪一面：N/E/S/W），写清依据（路口、地标、平面形状）。
4. **读立面**：每栋有截图的楼，按 `docs/mapping.md` 的判断顺序写：层数（数窗排）、墙面材料和颜色、窗型（点窗/带窗/幕墙）、开间大概几米、首层有没有不同、看得到的特色构件（外挂楼梯、架空、花格、柱廊）、门的位置和门头。只写截图里看得到的。
5. **索引** `docs/refs/video.md`：
   - 视频表：`| R 号 | 链接 | UP 主 | 发布日期 | 时长 | 路线 |`
   - 截图表：`| 截图文件 | 楼编号 | 楼名 | 朝向 | 定位依据 | 看到了什么 |`
   - 末尾统计：按 TASK-15～18 的四片（中心 y < 330、330–615、615–820、≥ 820），每片原来有照片几栋、这次新增几栋、还没资料几栋。
6. **档案** `docs/refs/buildings.md`：有新截图的楼更新那一行。
