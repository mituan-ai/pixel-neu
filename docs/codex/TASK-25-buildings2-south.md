# TASK-25：南片校内楼第二轮精修（中心 y 615–820）：视频截图和组团参照

## 目标

第一轮（TASK-15～18）因为没照片，南片大部分楼还是中性立面。这一轮用 TASK-22 建好的视频截图索引，把有截图的楼逐栋写上外观；仍然没有截图的楼，按「组团参照」兜底。做完后这一片尽量不再有中性立面，留下的每一栋都在档案里写明原因。

## 范围

`node tools/looks.ts --list 615 820` 列出的楼。别的分区的楼一律不动（另外三张任务单同时在做）。

## 依据（按优先级，后面的和前面的冲突以前面的为准）

1. **照片和视频截图**：`docs/refs/video.md`（TASK-22 的截图索引：哪张截图是哪栋楼的哪一面、看到了什么），截图在 `data/ref/video/`；`docs/refs/buildings.md`、`docs/refs/buildings-south.md` 里已有的照片。层数数截图上的窗排。
2. **卫星图**：`npm run check -- 2025-07-31 <楼框外扩 10 m> 8` 和 `2026-10-29` 两期：量墙脚、门的位置（雨棚、台阶、门前铺装）、外挂楼梯，看屋面颜色和坡顶。
3. **组团参照**（兜底，尽量不用）：前两条都定不了立面的楼，按 `docs/mapping.md`「组团参照」一条写 `like`。

## 先翻视频

TASK-22 只给全校截了 10 张图，但 `data/ref/video/` 里 10 个视频（`BV*.mp4`，已下载，不用再下）拍到的楼远不止这些。这一轮每片自己翻一遍，专找本片的楼：

- 视频信息见 `docs/refs/video.md` 的视频表和候选表（R-vid-01～04 已登记；其余候选用到时按同样格式登记成新的 R 号，写进本片的 `docs/refs/buildings-south.md`）。
- 每个视频每 2 秒抽一帧（`ffmpeg -i 视频 -vf fps=0.5 -q:v 3 /tmp/<视频>/%04d.jpg`，抽到 `/tmp`，不要堆在 `data/` 里），先粗看哪些段落在本片。
- 定位靠：路口和路的走向、楼的平面形状、层数、屋面颜色、地标、门牌和视频字幕里的楼名，和卫星图对照（`npm run check`）。宿舍楼多半有楼号牌（「一舍」「九舍 A」），对着门牌认。
- 对上编号的，挑最正、最清楚的一两帧复制到 `data/ref/video/`，文件名照 `docs/refs/video.md` 的规则；在本片的 refs 文件里记截图索引（同 video.md 的截图表格式）。**对不上编号的不用**。
- 下载新视频只在本片缺口很大、现有视频确实没拍到时才做，单片不超过 500 MB。

## 可以改的文件

- `data/survey.json`：只改这一片的楼在 `buildings`、`newBuildings` 里的条目（`storeys`、`parts`、`roof`、`rise`、`look`、`tweak`、`like`、`features`、`name`、`src`），以及落在这一片楼上的 `doors`
- `docs/refs/buildings-south.md`：补本轮用到的资料和逐栋记录
- `docs/refs/buildings.md`：只改这一片的楼那几行的「状态」：「已精修」「组团参照」或「没资料，保持中性」（写原因）

不改 `tools/` 下任何文件。需要新楼型、新构件、或者现有参数表达不了的做法（例如一栋楼不同的面做法不同），写进回复，由维护者加。

## 步骤

每栋楼：

1. 查 `docs/refs/video.md` 和档案，看这栋楼有没有截图或照片。
2. **有截图或照片**：
   - 层数：数窗排，写 `storeys`；局部高低不同写 `parts`。
   - 楼型：按墙面材料、颜色和窗型从 `LOOKS` 挑最像的写 `look`，只差墙色、窗宽、开间的写 `tweak`。裙楼和主楼做法不同的，在 `parts` 里给分区写 `look`。
   - 特色构件、门、坡屋顶：照片上能认出来的才写，写法同第一轮（`docs/mapping.md`）。位置从卫星图量，取整到 0.5 m。
   - `src` 追加截图所在视频的 S 号和 R 号。
3. **没有截图和照片**：看同组团（相邻、同年代、平面和层数相近，例如同一排宿舍、同一组教学楼的分翼）里有没有一栋已经有 `look` 并且不是参照来的楼：
   - 有：写 `like: 那栋楼的编号`，`src` 追加「组团参照」和那栋楼的 R 号；档案状态写「组团参照」，并写清楚为什么算同组团。
   - 没有：保持中性，档案写原因。
4. 每改完 3–5 栋，跑一次 `node tools/looks.ts <这几栋的编号>`，打开 `data/looks-sheet.png` 和截图并排比，不像就调参数。
5. 改完这一栋，改档案里那一行的「状态」。
