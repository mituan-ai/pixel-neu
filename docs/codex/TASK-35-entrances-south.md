# TASK-35：南片楼门、楼洞、连廊（楼中心 y 615–820）

## 目标

这一片每栋校内楼都有门，人知道从哪进楼；看得见的楼洞（穿过楼的过道）和连廊（楼与楼之间架空的走廊）画出来，底下能走。

## 范围

`node tools/looks.ts --list 615 820` 列出的楼，逐栋处理。别的片的楼一律不动（另外三张单同时在做）。

## 依据

- 卫星图：每栋楼只截它自己周围：`npm run check -- 2025-07-31 <楼框外扩 15 m> 8`，看不清再换 `2026-10-29`。楼框从 `--list` 的中心和占地算
- 视频截图：`docs/refs/video.md`（哪张截图是哪栋楼的哪一面，门、门牌、过道）；`docs/refs/` 里这一片的档案
- 规则：`docs/mapping.md`「楼的外观」第 5 条（门）和「楼洞和连廊」

## 相关文件（只读）

- `AGENTS.md`、`docs/mapping.md`
- `tools/survey.ts`：`doors`、`Part`（`lift`）、`newBuildings`（`lift`、`height`）

## 可以改的文件

- `data/survey.json`：`doors` 里这一片楼的门；这一片楼的 `buildings` 条目里加 `parts`（楼洞）；`newBuildings` 里加连廊；`areas` 里加楼洞底下和门前的 `paving`
- `docs/refs/` 里这一片的档案：每栋楼一行，写门、楼洞、连廊的依据或「看不出」
- `docs/sources.md`：「待核实」

## 怎么判断（按这个顺序，找到一条就够）

**门**：
1. 视频截图上看得到门的，按截图定位置和门头。
2. 卫星图上：伸到墙脚的步道或铺装的尽头、墙外凸出的雨棚或门斗（比墙面亮或有投影的小方块）、台阶、门前一小块铺装、几辆单车堆在墙边。
3. 宿舍楼、教学楼常见的做法是正门在朝路或朝广场的长边上：**只有**在第 2 条找到至少一个迹象落在这条边上时才按这条定位置。
4. 一条迹象都没有的楼不写门，档案里写「看不出」。

门的写法：`at` 落在墙脚线上（取整到 0.5 m），`facing` 朝外，主要入口写 `main: true`；门头按截图选，没截图就写 `"canopy":"none"`。

**楼洞**：卫星图上楼两侧的路或步道正对着、在楼的同一位置断开，或者视频截图上看得到穿过楼的洞口。写法见 `docs/mapping.md`「楼洞和连廊」：楼的 `parts` 里加一个 `poly`（洞宽 × 楼进深），`lift` 一层写 3.6；洞底在 `areas` 加一条 `paving`。

**连廊**：卫星图上两栋楼之间一条宽 3–6 m 的窄屋面，两侧地面是通的（路、步道从底下穿过，或者两边都是同一片绿地）。在 `newBuildings` 里描它的墙脚（两端各伸进两栋楼的墙 0.5 m），`storeys` 写它连到的层数，`lift` 和 `height` 按截图数层；没有截图写 `lift: 3.6`、`height: 7.2`，记「待核实」。卫星图上那一条如果底下看不出是空的，按实心楼描，不写 `lift`。

## 步骤

1. `node tools/looks.ts --list 615 820` 列出楼，先处理门数为 0 的楼，再看已有门的楼有没有楼洞、连廊。
2. 每栋楼：截 check 图看，查视频索引，按上面的判断写数据，在档案里记一行。不要每栋都跑全图生成。
3. 每做完 8–10 栋，跑一次 `node tools/looks.ts <这几栋的编号>`，看门和洞在对的墙上。
4. 全部做完跑一次验收。
