# TASK-28：北门一带和北侧衔接重描

## 目标

北门是进游戏第一眼看到的地方，现在这一带和卫星图差得最多：北门以西的南湖公园是一整块纯绿，和描过的林地之间是直角硬边；门内西侧有一栋楼被画成了米色铺装块加一圈路；门前广场、北门外马路和东北侧地块拼得生硬，大片画成铺装的地方卫星图上是树。做完后从北门进来，四周的路、树、楼和卫星图对得上，看不到硬边。

## 范围

世界米坐标 x -588–400、y -60–200（地图北缘到信息学馆北墙）。分两档：

- **细描**（x -200–400）：按 `docs/mapping.md` 校内的精度。
- **粗描**（x -588–-200，南湖公园和西北校外）：按校外的精度，只描大块：湖面、主园路（宽 ≥ 4 m）、广场、林地、草坪；园内的楼按卫星图补成 `newBuildings`，层数看不出写 2 并记「待核实」。

y > 200 的东西一律不动（另一张单在做）。

## 依据

- 卫星图对照图：`npm run check -- 2025-07-31 x0 y0 x1 y1 8`，范围按 100 × 100 m 一块切；树荫下看不清的再用 `2026-10-29` 那期对照
- 现状对比：`npm run compare -- x0 y0 x1 y1 4`（左边是现在画出来的，右边是卫星图）。注意左边的楼顶按高度往北抬，楼看起来比卫星图偏北，楼的位置以 check 的红线为准
- 视频截图：`docs/refs/video.md`，北门、信息学馆一段（R-vid-01、R-vid-03）；`docs/refs/gate.md`、`docs/refs/gates.md`、`docs/refs/park.md`、`docs/refs/plaza.md`

## 步骤

1. 先跑 `npm run compare -- -588 -60 400 200 2` 看全貌，再按下面顺序逐块处理，每块改完跑 `npm run map && npm run art`，用 compare 复查。
2. **南湖公园**（x -588–0、y -60–150）：
   - 湖面 `water`（北缘的湖，沿岸线描多边形，顶点 2 m）；
   - 主园路 `paving`（line + width），沿湖的环路、通向北门外马路的入口；
   - 广场、园内建筑前的铺装；园内楼补 `newBuildings`；
   - 其余按树冠写 `wood`、开阔处写 `grass`。
   - 公园和校园之间的围墙线是现有的校界，不动。
3. **北门内西侧**（约 x -30–60、y 40–110）：卫星图上有一栋深色屋顶的楼（约 x -11–39、y 59–98），现在画成米色块和一圈路。查 OSM（check 图的红线）：有轮廓就修 `shift`，没有就在 `newBuildings` 里描墙脚；楼前停车场写 `parking`，那一圈路按卫星图改。
4. **北门内外**（x 80–200、y -60–60）：门外马路、门前广场、斑马线；北门正对的南北路宽按卫星图量；门口两侧的树和铺装。斑马线写进 `marks`（`zebra`），路口停止线写 `stop`。
5. **东北侧**（x 180–400、y -60–200）：按卫星图把成片的树改回 `wood`/`grass`，铺装只留楼前和停车场；车行道走向和宽度对卫星图；缺的楼补 `newBuildings`，对不上的 OSM 楼修 `shift` 或 `drop` 重描。
6. **硬边**：所有新描的面和已有的面接边时直接用已有面那条边上的坐标；描完 compare 看一遍，不能再有直角的纯绿块、纯米色块。
