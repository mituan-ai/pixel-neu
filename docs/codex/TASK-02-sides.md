# TASK-02：描两侧楼群和北边两角的地面

## 目标

现在地图只描了中间 x 50–213 m，两侧和北边两角是深色的校外格，侧楼也就没有画出来。
把这几块的地面、单棵树和楼基平移量描进 `data/survey.json`。描完后两侧的路、草地、林地、停车场都能显示，OSM 里的侧楼会自动画出来。

## 范围（世界米坐标，上北）

| 块 | x | y |
|---|---|---|
| A 西侧 | 0–52 | 0–488 |
| B 东侧 | 211–272 | 0–488 |
| C 西北角 | 52–102 | 0–87 |
| D 东北角 | 158–211 | 0–87 |

`data/survey.json` 里已有的面不改、不删。

## 依据

- 卫星图：2025-07-31 版是主依据，夏季、阴影短。
  - 先跑 `npm run sat -- 2026-10-29`，这一版是 2025-11 拍的落叶期，用来看树冠下的路和单棵树。
  - 两版有几米的错位时，以 OSM 楼轮廓（对照图里的红线）为准配准。
- 对照图：每块按 100 m 高切片，每米 8 像素，例如：
  ```
  npm run check -- 2025-07-31 0 0 52 100 8
  npm run check -- 2026-10-29 0 0 52 100 8
  ```
  输出在 `data/check.png`，每次会覆盖，看完再出下一张。图上的标记：
  - 黄线是网格，每 5 m 一条，每 10 m 标一个坐标。
  - 红线是 OSM 楼轮廓，紫线是平移后的楼基。
  - 彩色细线是 survey 的面：蓝沥青、橙铺装、青停车场、绿草地或林地、粉绿篱。
- 侧楼名称见 `docs/refs/sides.md`。这次只描地面，不起名。

## 步骤

1. 按 A、B、C、D 的顺序，一块一块地对每张切片描图。
2. 每张切片按这个顺序追加面：
   1. 先描大面：`grass` 草地、`wood` 树冠连成片的林地。
   2. 再描上面的东西：`asphalt` 车行道、`paving` 人行道和广场、`parking` 停车场、`hedge` 绿篱、`water` 水面。
3. 顶点规则：
   - 顶点取整到 0.5 m。
   - 路沿直线的地方只放两端两个点，不要沿弧线描一串锯齿。
   - 弯道每 3–5 m 一个点。
4. 和已有面接边：
   - 新面不能盖到已有的面上。
   - 接边时，顶点直接用已有面那条边上的坐标。比如西侧路（areas 第 21 项）的西边是 x = 50，你的面东边也写 x = 50。
5. `parking` 只用于车身南北向（车头朝北或朝南）的车位排，因为生成器只会这样停车。
   - 车身东西向的车位排描成 `asphalt`，并在「待核实」里记下范围，写明「东西向车位，待维护者摆车」。
6. 单棵树：林地以外看得清的单棵树，写进 `trees`，格式为 `[x, y, 冠幅半径]`。
   - 冠幅半径取 2–4 m，按卫星图上的树冠量。
   - 林地里面的树不要单独描。
7. 楼基平移：
   - 范围里的 OSM 楼有 514993668、514995514、514995513、514995512、514993670。
   - 对照图上红线（OSM 轮廓）和卫星图上的楼基（贴地的墙脚，不是楼顶）错开超过 1.5 m 的，在 `buildings` 里记 `"<id>": { "shift": [dx, dy] }`，单位米。
   - 估法：看楼的阴影一侧的墙脚线。
8. 卫星图上有楼、但 OSM 里没有红线的：
   - 楼的占地描成 `paving`。
   - 在「待核实」里记一行：范围、「OSM 无此楼，占地暂作铺装」。
   - 不要画楼，也不要起名。
9. 看不清的地方（树荫、阴影里）：
   - 按两侧能看清的部分连起来。
   - 在「待核实」里记一行：范围、依据、需要什么资料。

## 数据格式

照抄已有的写法，一个面一行：

```json
{ "kind": "asphalt", "poly": [[205, 228], [213, 228], [213, 488], [205, 488]] },
```

```json
"trees": [[30.5, 212, 3], [34, 220.5, 2.5]],
"buildings": { "514993670": { "shift": [-2, 1.5] } }
```
