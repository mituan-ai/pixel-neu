# TASK-05：校内楼基重量、路面细化、运动场、花坛路灯、校门和纪念物

## 目标

TASK-04 把全校的路和楼摆上了，这张任务单把校内做细。做完后，在游戏里走一圈应该看到：

- 每栋楼的大小、形状和卫星图上的墙脚一致，翼宽不再忽宽忽窄，层数可信。
- 路是连续的带子：弯路有圆弧，路口转角是圆的，路宽按实测。
- 体育场有看台，各类球场有场线和颜色。
- 广场有花坛，主要道路有路灯。
- 东、西、南门有门的样子；火箭、雕塑、刘长春像、一二九塑像、能量球有各自的造型。

**本任务单分 7 部分（A–G），B–F 已完成，剩 A 和 G，要在一次会话里做完。** 每做完一部分就在文末「进度」表里记一行；会话中断时，下次从没记的那部分接着做。

## A. 楼：校内楼基和层数重量

校内的楼（中心在校界内）逐栋过一遍。校外的楼不动。

**2026-11-02 改写**：原来要求每片先找参考楼标定，再跑视差工具，这一步做不下去，现在取消。A 改成直接按墙脚量，不需要 `tilt`，视差工具只作参考。

### A1. 原理

- 卫星图斜着拍，楼顶会朝背离相机的方向偏，偏多少和楼高成正比。朝向相机的那几面立面会露出来。
- **墙脚**是露出的立面和地面的交线。它不随楼高偏，两期卫星图上在同一个位置。楼基就按墙脚定。
- 两期是从不同方向拍的，露出的面不一样。比如八舍一带：2025-07-31 露出西面的白色立面，2026-10-29 露出北面的立面。所以一栋楼的四条边，通常每条都能在其中一期看到墙脚。

### A2. 逐栋量

范围按 TASK-04 的 36 块分片，只做含校内楼的块。每栋楼：

1. 出两期对照图：`npm run check -- 2025-07-31 <楼框外扩 10 m> 8`，再用 `2026-10-29` 出一张同样范围的。
2. 四条边（U 形、L 形楼是每一翼的每条边）逐条找墙脚：
   - 有一期露出了这一面的立面：墙脚就是这条立面的下沿。
   - 两期都没露出这一面（被树、阴影、别的楼挡住）：看对边。同一翼的宽度，等于露出立面那一期的楼顶宽度。用对边的墙脚加上这个宽度，得到这条边。
3. 按量出的墙脚，二选一：
   - 和 OSM 轮廓只差一个平移：写 `shift`，取整到 0.5 m。
   - 每条边差得不一样（翼宽不对、形状不对）：写 `drop`，在 `newBuildings` 里按墙脚重描。
   - **不再新增 `lean`。**
4. 层数：数露出立面上的窗户排数。两期都数一下，取能数清的那期。数不清的保持现值，在「待核实」里记一行。
5. 墙脚和 OSM 轮廓相差都在 1 m 以内的楼：不改，在进度表里计入「已核对」。

### A3. 视差工具（可选）

`npm run parallax -- x0 y0 x1 y1` 的「楼顶」两列，是两期楼顶相对 OSM 轮廓的位置。

- 用法：帮你判断这片的斜拍方向，以及哪栋楼高。两期楼顶差得越多，楼越高。
- 不用写 `tilt`，不直接采用「建议 shift」。

### A4. 先做哪些

先做点名的楼（A5）和 5 层以上的楼，再做其余的楼。3 层及以下的楼，OSM 轮廓偏差通常在 2 m 以内，按 A2 第 5 条快速过。

  - 西侧的低矮附属楼另描成 `newBuildings`。

## C. 运动场

   - 场地底色保持或补描 `court` 面。

     - `type` 按卫星图上的场线判断：篮球场是长方形加两端半圆区，网球场是长方形加中间网线，排球场比篮球场小。
