# TASK-03：把东西向车位排写进 survey.json

## 目标

TASK-02 里描成沥青的东西向车位排，逐排写进 `data/survey.json` 的 `stalls`。写完后这些地方会画出车位线，八成车位停上车。

## 范围

只处理 `docs/sources.md`「待核实」里 TASK-02 记下的这几处车位：

| 处 | x | y |
|---|---|---|
| 1 | 260–272 | 35–100 |
| 2 | 194–211 | 0–35 |
| 3 | 213–230 | 200–266 |
| 4 | 225–263 | 300–335 |
| 5 | 235–251 | 426–446 |

## 依据

- 对照图：`npm run check -- 2025-07-31 <x0> <y0> <x1> <y1> 8`，每处一张，范围在上表基础上四周各放 5 m。
- 车位线看不清时，看停着的车：车身朝向就是车位朝向，车头或车尾挨着的那条线就是底线。

## 相关文件（只读）

- `tools/survey.ts`：`stalls` 字段的定义
- `tools/map.ts`：搜「垂直车位排」，看车位怎么从 `stalls` 算出来
- `data/survey.json`：末尾已有的 4 排 `stalls`，是信息学馆院内的，照抄写法

## 可以改的文件

- `data/survey.json`：只在 `stalls` 数组末尾追加
- `docs/sources.md`：
  - 把上表 5 处对应的「待核实」行，「现状」一列改成「已写入 stalls」。
  - 量不准的另起新行。

## 步骤

1. 每处出一张对照图，找出每一排车位：
   - **底线**：车位靠里的那条长线，车头或车尾顶着它。
   - **back**：底线在车位的哪一侧，取 `N`、`E`、`S` 或 `W`。
     - 东西向停的车：底线在车位西边写 `W`，在东边写 `E`。
     - 南北向停的车：底线在北边写 `N`，在南边写 `S`。
   - **at**：底线的起点。
     - back 是 `W` 或 `E` 时，取底线北端。
     - back 是 `N` 或 `S` 时，取底线西端。
     - 坐标取整到 0.5 m。
   - **n**：车位数，等于排长除以 2.5 m，取整。
2. 两排背靠背共用一条底线时，写两条：同一个 `at`，back 一个 `W` 一个 `E`（或一个 `N` 一个 `S`），照抄院内停车场中间那两排。
3. 南北向停车的排也照样写进 `stalls`，不要描成 `parking` 面。
4. 车位排所在的地面必须是 `asphalt`，TASK-02 已经描好，不要再改 `areas`。
5. 跑 `npm run map`。
6. 再出一遍每处的对照图，加 `npm run art` 后看 `data/preview.png`，逐项核对：
   - 车位线和车都落在沥青上。
   - 没有压到草地、楼或路中线。

## 数据格式

```json
"stalls": [
  { "at": [111, 261], "n": 9, "back": "W" },
  { "at": [262.5, 40], "n": 22, "back": "E" }
]
```
