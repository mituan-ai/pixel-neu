# TASK-11：校内楼名、地标介绍、楼门和单车停放点

## 目标

现在全图只有 11 个兴趣点，校内的楼大多没有名字。这张任务单要做四件事：

1. 给校内的楼起名，名字要有资料依据。
2. 给主要的楼写介绍卡片。
3. 标出楼门。
4. 标出单车停放点和电动车棚。

做完后，在游戏里走到楼门口会弹出介绍。后面的猫、单车也会用到门和停放点。

## 范围

校内的楼，也就是中心在校界内的楼，和 TASK-05 A 部分是同一批，共 157 栋。校外不动。

## 依据

- **楼名**，按可信度从高到低：
  1. 学校官方网站和校园地图上的楼名。
  2. OSM 的 `name` 标签（`data/osm.json`）。
  3. 新闻报道、学院官网写的楼名和地址。
  - 每个来源先登记到 `docs/sources.md`，拿到 S 号再引用。
  - 楼名只写资料里明确写了的。拿不准是哪一栋的，不起名，写进「待核实」。
- **介绍：**
  - 只写资料能证实的事实，比如建成年份、用途、命名由来、楼里有哪些学院。每句话都要有来源。
  - 写法参照 `tools/map.ts` 里 POI 的现有介绍：短句，不写评价和形容词。
  - 来源编号只放在 `src` 字段里，正文里不出现「[S21]」这类编号。
- **楼门和停放点**：
  - 从两期卫星图对照图上量。门看门前的台阶、雨棚、通往楼的小路；停放点看成排的车。
  - 命令：`npm run check -- 2025-07-31 <x0> <y0> <x1> <y1> 8`，再用 `2026-10-29` 出一张同样范围的。
  - 看不清的不标。

## 相关文件（只读）

- `tools/survey.ts`：`buildings[id].name`、`newBuildings[].name`、`doors`、`bikeRacks`、`places` 这几个字段的含义
- `tools/map.ts`：现有 POI 的写法；`places` 怎么变成兴趣点
- `data/osm.json`：楼的 OSM 编号和 `name` 标签
- `docs/sources.md`：来源编号和「待核实」的格式
- `src/ui.ts` 里的 `SOURCE_LABEL`：新 S 号的简称要补在这里

## 可以改的文件

- `data/survey.json`：`buildings` 里各楼的 `name` 和 `src`，`newBuildings` 里的 `name` 和 `src`，以及 `doors`、`bikeRacks`、`places` 三个数组
- `docs/sources.md`：登记新来源，记逐栋依据和待核实
- `src/ui.ts`：只在 `SOURCE_LABEL` 里补新 S 号的简称
- 本任务单：只改「进度」表

## 步骤

1. **楼名。** 逐栋查。有名字的，在 `survey.json` 这栋楼的条目里写 `name` 和 `src`；没有条目的楼，新建一个只有 `name` 和 `src` 的条目。同一栋楼被拆成几个 OSM 轮廓的（比如八舍有两个轮廓），每个轮廓都写同一个名字。
2. **楼门。** 每栋有名字的楼至少标出正门（`main: true`），能看清的侧门也标上。`at` 落在墙脚线上，`facing` 是门朝外的方向。
3. **介绍。** 教学楼、图书馆、食堂、体育馆、宿舍区，每类至少挑资料最全的几栋写 `places`，总数不少于 25 条。`at` 放在正门外 2–3 m 的路面上，必须是能走到的格子。已有的 11 个 POI 不要重复写。
4. **单车停放点。** 在教学楼、宿舍、食堂门口找成排停放的车，按排写 `bikeRacks`，有棚的写 `covered: true`。
5. **出图核对。** 每做完一片，跑 `npm run map && npm test`，确认新兴趣点从出生点能走到。

## 数据格式

```json
"buildings": {
  "<OSM 编号>": { "storeys": 5, "name": "<楼名>", "src": "S1,S30" }
},
"doors": [
  { "at": [123.5, 456], "facing": "N", "main": true }
],
"bikeRacks": [
  { "from": [120, 470], "to": [135, 470], "covered": true }
],
"places": [
  { "name": "<楼名>", "at": [123.5, 452], "text": "……。……。", "src": "S30,S31" }
]
```
