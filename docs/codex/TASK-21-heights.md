# TASK-21：全校楼高：视差标定和投影测高

## 目标

现在校内 157 栋楼里，大部分的层数是 OSM 的 `building:levels` 或者默认 4 层，没有核对过。做完后每栋校内楼都有一个有依据的层数：照片数的、视差测的，或投影量的；量不出来的在档案里写明原因。

## 范围

`node tools/looks.ts --list` 列出的 157 栋校内楼。只定层数和局部高起（`parts`），不动立面、楼名、门。

## 依据

- **照片**（最优先）：`docs/refs/buildings.md` 里「有照片」的楼，层数以照片数窗排为准，不用测量值改它。
- **视差**：`npm run parallax -- x0 y0 x1 y1`（原理见 `tools/parallax.ts` 开头）。现在 `survey.json` 的 `tilt` 是空的，工具解不出楼高，要先标定。
- **投影**：同一期卫星图上，楼在地面上的投影长度和楼高成正比，比例在同一期、同一片里不变。用参考楼量出「投影长 ÷ 楼高」，再量其他楼的投影长换算楼高。投影量法：`npm run check -- <期> x0 y0 x1 y1 8` 出对照图，沿太阳方向量楼墙脚到投影末端的米数（只量落在平地上、没被树和别的楼挡住的投影）。
- 一层按 3.6 m 左右估（教学楼常见 3.6–4.2 m，宿舍 3.0–3.3 m）；楼高换层数时按用途选，写在档案里。

## 相关文件（只读）

- `AGENTS.md`、`docs/mapping.md`（「楼的外观」判断顺序；层数这一条）
- `tools/parallax.ts`、`tools/survey.ts` 的 `tilt` 注释、`tools/geo.ts` 的 `SAT_SOURCES`
- `docs/refs/buildings.md`：哪些楼有照片

## 可以改的文件

- `data/survey.json`：`tilt`（标定）；校内楼的 `storeys`、`parts`、`shift`（只在视差给出可信的楼基平移、并且和卫星图墙脚对得上时改）；`src` 追加 R 号
- `docs/refs/heights.md`（新建）：标定和逐栋测高记录
- `docs/refs/buildings.md`：不改表格，只在末尾加一句指向 heights.md
- `docs/sources.md`：「待核实」

## 步骤

1. **参考楼**：从有照片、层数确定的楼里，每片（北、中、南、最南，分区同 TASK-15～18：中心 y < 330、330–615、615–820、≥ 820）各挑一到两栋：轮廓简单、楼顶清楚、周围没有高树。信息学馆两翼 5 层（照片 R-bld-02 北面全景）可以作北片参考。
2. **标定 `tilt`**：每片一条 `{box, ref, off}`。`off` 在两期对照图上量同一个路口或标线的错位。标定后对参考楼自己跑一遍，解出的层数应该等于照片层数，残差 < 1 m；不行就换参考楼。
3. **逐片测**：每片跑 `npm run parallax`，记下每栋楼的建议层数、楼高、相关系数和残差。相关系数 ≥ 0.6 并且残差 ≤ 1.5 m 的算可信。
4. **投影交叉核对**：每片在 2025-07-31 一期上，用参考楼求出「投影长 ÷ 楼高」，再量其他楼的投影换算楼高。视差不可信的楼，用投影的结果；两种方法都可信但差一层以上的，看对照图找原因，定不下来就写「待核实」，保留原值。
5. **写进 survey.json**：照片定的不动；其余楼按「视差可信 → 视差；否则投影可信 → 投影；都不行 → 保留原值」写 `storeys`。楼明显分段高低（视差图或投影上能看出一段比另一段高）的，用 `parts` 写高起的一段。`src` 追加 heights.md 的 R 号。
6. **档案** `docs/refs/heights.md`：
   - 参考资料表（R-hgt-01……：两期卫星图、对照图、视差图，格式照抄 `docs/refs/library.md`）；
   - 标定表：每片的参考楼、off、标定残差；
   - 逐栋表：`| 编号 | 名字 | 原层数 | 照片层数 | 视差层数（楼高 m、相关、残差） | 投影层数（投影长 m） | 采用 | 方法 |`，157 行；
   - 末尾统计：每种方法定了多少栋、改了多少栋、多少栋待核实。
