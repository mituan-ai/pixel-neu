# TASK-20：地面细节：纹理变体、路面标线和井盖、铺装分类、草地小径

## 目标

现在路面、铺装、草地各只有一种 16 px 小样反复平铺，路上除了中线什么都没有。做完后：

- 路面有补丁、裂缝、井盖，路口有斑马线和停止线，停车场有车位线；
- 铺装分广场砖、人行道砖、石板、彩色透水砖几种，按地方选；
- 草地有深浅斑块、零星小花、被踩出来的土路；林下有落叶和土；
- 走在任何一处，看不出明显的 16 px 重复格子。

## 范围

全图地面（`tools/ground.ts` 烘焙的分块图）。只有标线和铺装分类要按卫星图描，限校内。

## 依据

- 斑马线、停止线、成片的彩色铺装：卫星图上能看见的才描（`npm run check -- 2025-07-31 x0 y0 x1 y1 4`，再看 `2026-10-29` 一期）。看不清的不描。
- 井盖、补丁、裂缝、落叶、小花、土路：程序随机生成（按世界坐标哈希，每次生成结果一样），不按卫星图逐个描。
- 尺寸：斑马线每条 0.45 m 宽、间隔 0.6 m、长度等于人行横道宽（一般 4–6 m）；停止线 0.3 m 宽；井盖直径 0.7 m（圆形）或 0.6 m 见方。

## 步骤

1. **去重复**：每种材质的小样从 16×16 改成 32×32 或 64×64，变体数至少 4 个；选小样时除了按格子哈希，再按大尺度噪声（20–40 m 一个周期）调深浅两档，让大片草地、路面有自然的明暗斑块。
2. **路面程序细节**（只在 `asphalt` 上，离路沿 0.5 m 以内不放）：
   - 井盖：每 30–50 m 一个，沿路中线附近；
   - 补丁：深一档的矩形，每 40–80 m 一块，1–3 m 见方；
   - 裂缝：1 像素的折线，零星几条。
3. **铺装分类**：`AreaKind` 加 `plaza`（广场砖：大块浅色，偶尔一块深色拼花）、`sidewalk`（人行道砖：小块灰红相间的人字或工字铺）、`slab`（石板：大块错缝）、`permeable`（彩色透水砖：红或灰的颗粒面）。原来的 `paving` 保留，作为没分清时的默认。按卫星图把能分清的校内铺装改过来（十字广场、图书馆南广场、各楼前广场、主要人行道）。
4. **标线** `marks`：斑马线、停止线、导向箭头、停车位线、减速带，按卫星图描校内能看到的。画在路面材质上，用 `paint` 白色；减速带用黄黑相间（新颜色）。
5. **草地和林下**：草地上零星小花（两三种颜色，成簇）、深浅斑块；草坪上被踩出来的土路按卫星图描成新材质 `dirt`（只描卫星图上明显的）；林下地面加落叶和裸土斑。
6. 小地图（`minimap()`）按新材质取色，颜色和原来一类的材质接近。

## 数据格式

```ts
/** 路面标线：zebra 斑马线（from–to 是人行横道中线，width 是横道宽）；stop 停止线；arrow 导向箭头（at、dir 度、shape: straight/left/right）；bump 减速带（from–to） */
marks: ({ kind: 'zebra'; from: P; to: P; width: number } | { kind: 'stop'; from: P; to: P } | { kind: 'arrow'; at: P; dir: number; shape: 'straight' | 'left' | 'right' } | { kind: 'bump'; from: P; to: P })[];
```
